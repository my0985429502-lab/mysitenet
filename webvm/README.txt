JS-DOS offline-ready project (clean)

Этот архив содержит мобильную JS-DOS версию проекта (index_jsdos.html) и основной UI (index.html).
В архив НЕ включены крупные бинарные файлы по твоему требованию. Пожалуйста добавь в корень папки проекта:

- jsdos.min.js            (местная копия js-dos)
- wdosbox-misc.js        (локальная поддержка wasm)
- wdosbox.wasm           (wasm бинарник для wdosbox)
- freedos-1.2.0.img      (образ FreeDOS или любой другой .img)
- open-watcom-c-dos-1.9.exe  (если хочешь установить OpenWatcom)

Как использовать:
1) Распакуй архив в папку на телефоне или ПК.
2) Помести перечисленные файлы в ту же папку.
3) Открой index_jsdos.html (или запусти локальный webserver и открой index_jsdos.html).
4) Нажми "Запустить JS-DOS". Если всё положено правильно — эмулятор запустится.
5) Используй кнопку "Send File" для отправки дополнительных файлов внутрь DOS.

Подсказки:
- Если открываешь локально на Android, лучше использовать простой HTTP сервер (например, приложение "Simple HTTP Server") и открыть проект через http://localhost:8080/index_jsdos.html
- Если нужны, могу скачать и встроить все бинарники в архив (но ты просил не включать большие файлы).
