Язык программирования C

Что такое C

C — компилируемый язык программирования. Программа превращается в EXE.

Первая программа

#include <stdio.h>

int main() {
    printf("Hello, world!");
    return 0;
}

Компиляция

wcc hello.c

Основы

  • int — число
  • char — символ
  • if — условие
  • for — цикл

Ошибки новичков

  • забыли ;
  • нет stdio.h
  • не запущен SETENV.BAT
