Open Watcom C/C++ 1.9 — инструкция оператора

Open Watcom C/C++ 1.9 (DOS)

Инструкция для технического оператора

1. Назначение

Open Watcom C/C++ 1.9 — компилятор языков C и C++ для DOS и сред эмуляции (DOSBox, WebVM, виртуальные машины).

2. Обязанности оператора

  • Установка среды
  • Настройка путей
  • Запуск компиляции
  • Контроль ошибок

3. Установка

open-watcom-c-dos-1.9.exe

4. Настройка окружения (обязательно)

C:\WATCOM\SETENV.BAT

Без выполнения SETENV.BAT компилятор работать не будет.

5. Основные команды

wcc hello.c      // компиляция C
wpp test.cpp     // компиляция C++
wlink file hello.obj

6. Типовой порядок работы

  1. Запустить DOS / DOSBox / WebVM
  2. Выполнить SETENV.BAT
  3. Перейти в каталог проекта
  4. Запустить компиляцию
  5. Проверить ошибки

7. Частые ошибки

  • wcc not found — не выполнен SETENV.BAT
  • out of memory — мало памяти в эмуляторе
  • file not found — неверный каталог

8. Использование в WebVM

Рекомендуется автоматический запуск SETENV.BAT через AUTOEXEC.BAT и использование FAT16-образа.

Документ предназначен для технического оператора.
