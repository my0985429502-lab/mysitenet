Идея программы

Программа написана на C (Open Watcom) и запускается в:

  • DOS / FreeDOS
  • DOSBox
  • WebVM

Она открывает сетевой порт и работает как минимальный веб-сервер, без Linux, Windows и Apache.

↑ наверх

Что делает сервер

  1. Инициализирует сетевой стек DOS
  2. Открывает TCP-порт (например 8080)
  3. Ждёт подключение браузера
  4. Принимает HTTP-запрос
  5. Отправляет HTML-страницу
  6. Закрывает соединение

В результате браузер отображает сайт, запущенный программой на C.

Архитектура

[ Браузер ]
      |
      | HTTP
      |
[ TCP/IP стек DOS ]
      |
[ Сервер на C (Open Watcom) ]
      |
[ HTML-ответ ]

Вся логика сервера реализована вручную, без библиотек высокого уровня.

Как работает HTTP в этом примере

  • HTTP обрабатывается вручную
  • Парсится только первая строка
  • Отдаётся статическая HTML-страница

Это минимальная реализация протокола HTTP.

Как запускается сайт

  1. Запустить DOS / DOSBox / WebVM
  2. Настроить TCP/IP (mTCP)
  3. Выполнить SETENV.BAT
  4. Запустить сервер: 
    server.exe
  5. Открыть в браузере: 
    http://IP:PORT

Зачем этот пример

Этот пример показывает, что язык C (Open Watcom) способен:

  • работать с сетью

  • работать даже в DOS
