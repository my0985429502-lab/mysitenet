Инструкция

Если хочешь, чтобы кампания создавалась автоматически в Google при нажатии, вставь свои Google креденшлы в backend/.env (см. .env.example). Если ты не знаешь, MCC или обычный аккаунт — оставь LOGIN_CUSTOMER_ID пустым.

Как понять MCC: войди в Google Ads — если у тебя есть список клиентов в интерфейсе и ID выглядит как 123-456-7890 и ты управляешь другими аккаунтами — это MCC. Если нет — твой аккаунт обычный.

Инструкция по настройке Google Ads

  1. Создайте Google Ads Manager (MCC).
  2. Получите Developer Token в разделе «Настройки API».
  3. Создайте OAuth Client ID в Google Cloud Console.
  4. Получите Refresh Token через OAuth авторизацию.
  5. Заполните backend/.env вашими данными.
  6. Запустите backend: npm install && npm start.
  7. Откройте frontend/index.html и запускайте кампании.
