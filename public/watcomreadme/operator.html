Оператор — Open Watcom

Инструкция для технического оператора

Назначение

Обслуживание компилятора Open Watcom C/C++ в DOS / DOSBox / WebVM.

Обязанности

  • Установка среды
  • Настройка окружения
  • Запуск компиляции
  • Контроль ошибок

Обязательная команда

C:\WATCOM\SETENV.BAT

Компиляция

wcc hello.c
wpp test.cpp

Типовые ошибки

  • wcc not found — не запущен SETENV.BAT
  • out of memory — мало RAM
