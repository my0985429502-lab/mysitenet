C/C++ для работников

Язык C/C++ для работников

Назначение

Сборка и сопровождение готовых программ.

Основные файлы

  • .c — исходный код
  • .h — заголовки
  • .exe — готовая программа

Типовые команды

wcc main.c
wpp program.cpp

Правила

  • Не менять код без задания
  • Проверять окружение
  • Фиксировать ошибки

Чеклист

  • DOS запущен
  • SETENV.BAT выполнен
  • EXE создан
