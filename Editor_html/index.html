Простой HTML Редактор

Статус: готов

Дизайн и описание

Цель
Простой и понятный редактор для быстрой разработки и проверки HTML/CSS/JS прямо на телефоне.

Структура
- Левый блок: три поля (HTML, CSS, JS).
- Правый блок: область с пояснением дизайна и превью внизу.

Цвета
- Тёмный фон для удобной работы ночью. Акцентный градиент для кнопки Run.

Инструкция
1. Вставь HTML в поле HTML.
2. Добавь стили в CSS и скрипты в JS.
3. Нажми Run или используй автообновление (включено).
4. Для сохранения — нажми Save Changes (сохранение в браузере) или Download .html для файла.

Примечание для Android
В мобильных браузерах превью открывается через srcdoc — это надёжно и безопасно.
